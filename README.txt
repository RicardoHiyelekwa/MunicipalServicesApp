APPLICATION OVERVIEW
----------------------------------------
This application is a C# Windows Forms system designed to improve municipal service delivery by allowing users to report issues such as sanitation, road problems, utilities, and more.

----------------------------------------
FEATURES IMPLEMENTED
----------------------------------------
1. Main Menu
- Report Issues (Fully implemented)
- Local Events and Announcements (Disabled for Part 1)
- Service Request Status (Disabled for Part 1)

2. Report Issues Functionality
- Users can input:
  • Location
  • Category
  • Description
- Users can attach files (images/documents)
- Each issue generates a unique reference ID
- Issues are stored using a List data structure

3. User Engagement Strategy
- A Progress Bar is used to guide the user
- Progress updates dynamically as fields are completed
- Encouragement messages improve user interaction

4. Additional Features
- View Submitted Issues in a DataGridView
- Validation for required fields
- File size validation (max 5MB)
- Success and error feedback messages

----------------------------------------
HOW TO RUN THE APPLICATION
----------------------------------------
1. Open the solution in Visual Studio
2. Build the solution (Ctrl + Shift + B)
3. Run the application (F5)

----------------------------------------
TECHNICAL REQUIREMENTS
----------------------------------------
- Visual Studio (recommended 2019 or later)
- .NET Framework

----------------------------------------
DATA STRUCTURES USED
----------------------------------------
- List<IssueReport> used to store reported issues efficiently
